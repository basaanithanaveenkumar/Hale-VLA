Hale-VLA: An Interleaved Vision–Language–Action Transformer with DeepSeek-Style MoE

A compact vision–language–action model written from scratch in PyTorch. Three special tokens let one causal transformer read images and robot state, and write text and continuous action chunks.

B A NaveenKumar
Independent research · 2026
Paper (PDF)CodeDocsBlog
TL;DR. Images are prepended, states are injected in place, and actions are read out from the hidden state of an <action> token. The decoder uses shared + routed SwiGLU experts. 356M parameters, trained on EO-Data1.5M with CE + masked-MSE.

Abstract

Vision–language–action (VLA) models extend multimodal language models so that the same network that describes a scene can also emit robot actions. Most open VLAs are built by fine-tuning a large pretrained VLM, which makes the architecture hard to inspect and expensive to modify.

Hale-VLA is a compact VLA written from scratch whose every component (patch encoder, causal decoder, mixture-of-experts layers, proprioceptive state encoder and continuous action head) fits in a few hundred lines. It represents images, robot state and actions as three special tokens added to the Qwen2.5 vocabulary, so arbitrary interleavings of observations, dialogue and control are expressed as one chat transcript. Each decoder block uses a DeepSeekMoE-style layer with always-on shared experts and noisy top-k routed experts. The default configuration has 356M parameters, with about 58M decoder parameters active per token, and is trained end to end with next-token cross-entropy on assistant turns plus a masked regression loss on actions.

Highlights

Unified token interface

<image>, <state> and <action> added to Qwen2.5 (ids 151665–151667). Any interleaving of frames, state, text and control is a single sequence.

Three integration patterns

Prepend for images (196 patches each), in-place injection for state, hidden-state read-out for actions.

DeepSeek-style MoE

2 shared + 8 routed SwiGLU experts, noisy top-2 routing, in all 12 decoder layers. The ViT uses 16 routed experts, top-4.

Chunked continuous actions

An MLP head maps each <action> hidden state to [chunk × action_dim]. No action binning in the vocabulary.

EO-Data1.5M pipeline

All 17 subsets (5 interleaved, 12 embodied QA), assistant-only supervision, per-batch padding of images, actions and states.

Built to be read

Every module is a small file with shape comments. Training renders videos of predictions against ground truth.

Status

The architecture, data pipeline and training loop are released. Benchmark results (embodied-QA accuracy, action MSE, ablations) are in progress and will be added to the paper and this page once runs are complete. No results are reported yet.

Quick start

git clone https://github.com/basaanithanaveenkumar/Hale-VLA && cd Hale-VLA
uv venv && source .venv/bin/activate && uv pip install -e ".[dev]"
python scripts/train.py --subset interleave-temporal --max_samples 100 --action_dim 32
import torch
from config import HaloVLMConfig
from models.halo_vla import HaloVLM          # PYTHONPATH=.:src/Halo_VLA

cfg = HaloVLMConfig()
model = HaloVLM(cfg).eval()
ids = torch.tensor([[cfg.image_token_id, 1, 2, cfg.state_token_id, 3, cfg.action_token_id]])
logits, actions = model(torch.randn(1, 1, 3, 224, 224), ids, torch.ones_like(ids),
                        torch.randn(1, 1, cfg.state_dim))
# logits: [1, 202, 151668]   actions: [1, 1, 1, 7]
